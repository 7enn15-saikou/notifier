# プレイガイド再販売 → Discord通知

指定した公演ページを定期的に確認し、券種のステータスが「受付中」に変わったらDiscordに通知します。
GitHub Actionsで動くので、PCを付けっぱなしにする必要はありません。**手動で開始**し、指定した時間（30〜300分）だけウォッチします。

## 使い方
1. Actionsタブ → `eplus-monitor` → Run workflow
2. 「監視する時間（分）」を入力（30〜300、初期値180）
3. 開始のお知らせをDiscordに送りたいときは、「開始のお知らせをDiscordに送る」にチェックを入れる
4. 時間が来ると、自動で終わります。続けるときは、もう一度 Run workflow を押す

## 通知の種類
- 🎫 券種が「受付中」になったとき（復活するたびに通知）
- 📢 開始のお知らせ（チェックを入れたときだけ）
- ⚠️ 受付状況を5回続けて取得できなかったとき（復旧したら ✅ で知らせる）
- ⏳ 終了の5回前（まもなく終了します）

## 設定を変えたいとき
- 確認の間隔：`monitor.yml` の `INTERVAL_SECONDS`（秒）
- 対象URLの追加：`urls.txt` に1行足す

## 注意
- 受付状況はリアルタイムに反映されないことがあります
- 間隔を短くしすぎないでください（アクセス制限の原因になります）
- ログに「受付状況を取得できませんでした」が続く場合は、アクセス制限やページ変更の可能性があります
